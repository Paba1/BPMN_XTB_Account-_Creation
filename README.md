📘 How to Use This Repository

This repository contains a university project for the Business Process Modelling course (Computer Science and Econometrics, 4th semester).

📂 Repository structure

project_xtb.pdf – complete project documentation, including process description, workplace model, document model, and reflections.

xtb_process_diagram.jpg – BPMN diagram (swimlane view) exported as an image for easier reading.

🧭 How to view

Simply open the project_xtb.pdf file to read the full report.
For a clearer look at the process flow, open the xtb_process_diagram.jpg image.

All materials were created for educational purposes to demonstrate skills in business process modelling using BPMN notation.
